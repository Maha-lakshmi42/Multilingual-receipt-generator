# Multilingual Receipt Generator

## Overview

Multilingual Receipt Generator is a web-based application developed as a final year B.Tech Computer Science and Engineering project. The system generates receipts in multiple languages and integrates QR code generation for easy verification and access to receipt information.

## Features

- Multilingual receipt generation
- QR code generation and integration
- User-friendly interface
- Receipt data management
- Data validation and processing
- Support for multiple receipt formats

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQL Database
- QR Code Libraries

## Project Structure

- app.py – Main application file
- qr_generator.py – QR code generation module
- transliterator.py – Language transliteration module
- templates/ – HTML templates
- static/ – Static resources
- schema.sql – Database schema
- requirements.txt – Project dependencies
